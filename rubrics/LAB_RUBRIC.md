# Weekly Lab Rubric (DS2002)

Each Friday lab is your graded weekly work. Labs are intentionally challenging — they replace traditional homework. Graded out of **100 points**.

| Criterion | Points | What earns full marks |
|-----------|--------|----------------------|
| **Correctness** | 40 | All required tasks completed; code produces the right result; edge cases handled where asked |
| **Notebook runs clean** | 20 | Restart + Run All executes top-to-bottom with no errors; outputs present |
| **Code quality** | 15 | Readable, sensible variable names, no dead/debug cells; comments only where logic is non-obvious |
| **Explanation** | 15 | Markdown cells explain *what* you did and *why*; findings stated in plain language |
| **Stretch / rigor** | 10 | Stretch tasks attempted; goes beyond the minimum where the lab invites it |

## Automatic point losses

- Notebook does not run: graded as-is (typically caps Correctness).
- Missing GitHub link or file in wrong folder: −10 (Canvas submission).
- No Markdown explanation anywhere: −15.

## Extensions

Two automatic 7-day extensions per semester (labs only). Use Canvas or DM before/at the deadline.
